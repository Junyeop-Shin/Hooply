# 요구사항 추적표 — 문제에서 검증까지

> 사용자 문제 하나하나가 어떤 요구사항이 되었고, 어떤 기능으로 구현했고, 어떻게 확인했는지를 표 하나로 이었습니다.
> 표의 내용은 모두 아래 "관련 문서"와 테스트 파일에서 확인할 수 있는 것만 적었습니다.

**읽는 법**

- **P** = 사용자 문제 번호 ([01 서비스 정의](01-서비스정의.md) 2.2절), **FR** = 기능 요구사항 번호(01 4.2절 · 07 4장), **F** = 기능 번호(01 3.2절), **S** = 화면 번호(02)
- **pytest** = 서버 자동 테스트 (`backend/tests/`), **E2E** = 실제 브라우저로 화면을 눌러 보는 자동 테스트 (`frontend/e2e/`). 모두 GitHub Actions 에서 푸시마다 실행됩니다
- 파일 이름 뒤 `::이름` 은 그 파일 안의 테스트 하나를 가리킵니다
