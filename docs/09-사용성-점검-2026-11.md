## 2. 남은 개선점 — 경기 당일 매니저 흐름

### ✅ 2-1. [상] 실제로 뛴 사람과 참석 응답이 따로 논다 → 투표 · 출석 · 배지가 틀어짐
- **장면** 응답 안 한 회원 A가 늦게 와서 뜀(경기 기록 "명단에 사람 넣기"로 넣음). 참석으로 답한 B는 안 옴.
- **지금** 명단 추가는 화면 상태만 바꾸고(`frontend/src/pages/quarters.tsx:250`), 쿼터 저장도 참석 응답을 고치지 않는다(`backend/app/services/quarter_service.py:170-197`). A는 투표를 못 하고(`peer_service.py:132-140`, 투표 배너 `pages/team.tsx:256`), 노쇼 B는 투표 후보 · 독려 분모에 들어간다(`peer_service.py:98-105`). 참여율 리더보드(`peer_service.py:664-670`) · 참석 배지(`badge_service.py:125`) · 선호 조합 분모(`peer_service.py:246`)도 같은 기준이라 함께 틀어진다.
- **제안** 쿼터 저장 때 출전 기록이 있는 사람은 ATTEND 로(`registered_by` = 매니저). 참석인데 출전 0인 사람은 "N명 불참으로 바꿀까요?" 한 번 묻기.

### ✅ 2-2. [상] "응답 미리 마감"은 되돌릴 수 없다
- **지금** 마감하면 OPEN → CLOSED(`event_service.py:97-103`)이고 다시 여는 길이 없다. 일정 수정은 상태를 건드리지 않아 마감 시각을 늘려도 안 열린다 — API 문서(`api/v1/events.py:117`)는 열린다고 적혀 있다. 마감 확인 문구(`lib/copy.ts`)도 되돌릴 수 없다고 말하지 않는다.
- **제안** "응답 다시 받기"(CLOSED → OPEN, 확정 전만). 문서 문구 바로잡기.

### ✅ 2-3. [중] 배정 실행 때 나온 경고가 결과 화면에서 사라진다
- **지금** 경고는 실행 응답(POST)에만 있고(`api/v1/assignments.py:89-90`), 화면은 결과 페이지로 가서 GET 으로 다시 받는데 GET 은 경고를 빈 목록으로 준다(`assignments.py:153`, `assignment_service.py:1189-1196`). "볼 운반 · 골밑 조건은 빼고 나눴어요"(`assignment_service.py:1032-1034`) · 3팀 인원 불균형(`1065-1070`)은 사전 검사에도 없어서 매니저가 영영 못 본다.
- **제안** 경고를 `run.params` 에 저장해 GET 에서도 돌려준다.

### ✅ 2-4. [중] 확정 안 한 배정안(직접 옮긴 것 포함)으로 돌아갈 길이 없고, 다시 실행하면 조용히 지워진다
- **지금** 결과 페이지 링크는 실행 직후 이동 하나뿐(`pages/assignment.tsx:81`). 다시 "3가지 배정안 만들기"를 누르면 손으로 고친 것까지 지운다(`assignment_service.py:1036`, `1087-1095`).
- **제안** 배정 화면 위에 "확정 안 한 배정안 이어 보기". 고친 안이 있으면 새로 실행 전에 묻기.

### ✅ 2-5. [중] 종료 시각이 지나면 "팀 나누기"가 사라진다 (서버는 허용)

## 3. 남은 개선점 — 가입 · 팀 관리 · 기록 · 그 밖

### ✅ 3-1. [상] 카카오 초대 링크로 들어온 신규 가입자는 로그인하면서 팀 코드를 잃는다
- **장면** 단톡방 초대 링크(`/teams/join?code=…`)를 로그인 전 상태로 엶. 카톡 인앱 브라우저는 저장소가 따로라 기존 회원도 로그아웃 상태인 경우가 많다. 투표 링크 · 배정 결과 링크도 같다.
- **지금** 로그인 안 했으면 `<Navigate to="/login" replace />`(`frontend/src/App.tsx:52`) — 원래 주소를 버린다. 로그인 · 가입 · 카카오 뒤에는 늘 홈(`pages/auth.tsx:70`, `105`, `162`).
- **제안** 원래 주소를 `state.from` 으로 넘기고, 카카오로 나가기 전엔 localStorage 에 둔다. 로그인 뒤 그 주소로.

### ✅ 3-2. [상] 이메일로 가입한 사람이 "카카오로 시작하기"를 누르면 빈 새 계정이 조용히 생긴다
- **지금** 연결된 카카오가 없으면 새 계정을 만들고, 같은 이메일이 있으면 이메일만 비우고 계속 만든다(`kakao_service.py:135-144`). 프론트는 `is_new` 를 무시(`pages/auth.tsx:68-70`). 다시 팀에 들어가면 같은 사람이 둘인데 회원끼리는 합칠 수 없다(`guest_service.py:240-241`). 원래 계정에서 카카오 연결을 누르면 409 만 나오고 해결 방법은 안 알려 준다.
- **제안** `is_new` 일 때 "새 계정이 만들어졌어요. 이메일로 가입한 적 있나요?" — 있으면 방금 계정을 지우고 이메일 로그인 → 카카오 연결로 안내.

### ✅ 3-3. [상] 팀에 보이는 이름이 가입 때 정해지고 아무도 못 바꾼다 (카카오 가입자는 카톡 닉네임 고정)
- **지금** 카카오 가입 시 이름 = 카톡 닉네임(`kakao_service.py:138-139`), 팀 가입 때 `display_name` 으로 복사(`team_service.py:208`), `PATCH /me` 는 이걸 안 바꾼다(`api/v1/auth.py:264-265`, 화면 문구 `pages/profile.tsx:146`). 매니저가 고칠 수 있는 이름은 게스트뿐. 배정표 · 기록 · 공유 이미지에 "민수🏀"가 영구히 남는다.
- **제안** 이름을 바꾸면 활성 팀의 표시 이름도("팀에도 적용"). 매니저가 회원의 팀 표시 이름을 고칠 수 있게. 카카오 첫 가입 때 실명 한 번 묻기.

### ✅ 3-4. [중상] 게스트 기록을 잘못 이어 줘도 되돌릴 화면이 없다 (화면 · 도움말은 "되돌릴 수 있어요")
- **지금** 본인 확인은 이름만 맞으면 바로 합친다(`guest_service.py:355-363`, `pages/home.tsx:232`). 매니저 화면(`pages/team.tsx:543`, `548`) · 도움말(`lib/help-content.ts:174`)은 되돌릴 수 있다고 하지만, 되돌리기 API(`api/v1/guests.py:172-176`)가 프론트에 연결돼 있지 않다.
- **제안** 선수 상세에 "이어받은 게스트 기록 · 되돌리기". 그 전까지는 문구를 뺀다.

### ✅ 3-5. [중] 이름이 다른 게스트는 이어 줄 수 없고, 동명이인 후보는 영원히 남는다
- **지금** 본인 확인이 막히면 "매니저에게 말해 주세요"(`guest_service.py:356`)인데, 매니저 화면은 이름이 같은 짝만 보여 준다(`guest_service.py:285-293`, `pages/team.tsx:534-556`). 다른 사람인 동명 짝은 숨길 방법이 없다.
- **제안** 팀원 관리에 "게스트 기록 이어 주기"(게스트 검색 → 회원 선택, API는 이미 지원). 후보에 "다른 사람이에요" 숨기기.

### ✅ 3-6. [중] 실력 정렬을 저장하면 새로 온 회원이 아무 표시 없이 꼴찌로 저장된다
- **지금** 지난 정렬 뒤 가입한 사람은 맨 뒤에 붙고(`pages/ranking.tsx:29-37`) 저장 때 그대로 보낸다(`41`). 꼴찌 순위가 사전값의 절반(`survey_service.py:416`, `464`). "되돌릴 수 있어요"(`ranking.tsx:61`)라지만 이력 화면이 없다.
- **제안** 순서 없는 사람은 "아직 순서 없음" 칸에 따로, 옮기지 않으면 저장에서 뺀다(설계 8.5 "다음 정렬 때 편입"). 이력 · "이 순서로 되돌리기".

### ✅ 3-7. [중] 실수로 제외한 회원을 되돌리는 방법이 팀 코드 재발급뿐 — 제외했던 모든 사람이 함께 풀린다
- **지금** 제외된 사람은 지금 코드로 못 들어오고(`team_service.py:163-164`), 재발급하면 전원 풀림(`237-239`) · 단톡방 초대 링크도 무효. 나간 · 제외된 사람 목록 화면도 없다(`api/v1/teams.py:158-161`).
- **제안** "나간 · 제외된 사람" 목록과 개별 "제외 풀기", 코드 재발급과 분리.

### ✅ 3-8. [중] 회원 포지션을 매니저가 못 고치고, 설문을 안 한 회원은 본인도 못 고친다
- **지금** 포지션 편집기는 설문을 마친 사람에게만(`pages/profile.tsx:47-54`), 매니저는 게스트만(`guest_service.py:71-72`). `PUT /me/positions` 는 모든 팀에 같은 값을 덮는다(`api/v1/surveys.py:104-117`). 설문 건너뛴 회원은 "포지션 미입력"으로 남아 1번 · 5번 확보 계산이 틀어진다.

### ✅ 3-9. [중] 경기 후 투표 안내 띠가 지난 일정마다 쌓인다 (지난 기록 추가로 넣은 몇 달 전 경기 포함)
